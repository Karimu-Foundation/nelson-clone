# Skill: communication-style

## What it does
Applies `knowledge/communication-style.md` consistently to anything the agent drafts "as Nelson" — so output sounds like Karimu's actual voice, not a generic AI assistant.

## When to use
Every time the agent produces text meant to go out under Nelson's name or Karimu's institutional voice: emails, Leadership Team notes, volunteer updates, donor/partner correspondence, annual report copy, social/website copy.

## Checklist before returning any draft
01. **Specific over abstract.** Replace vague impact language with a number, a ward name, or a named role/country if one is available in `knowledge/`.
02. **No banned phrases.** Scan for "synergies," "leverage," "ecosystem," "holistic," "capacity building" used as filler, and cut them.
03. **Community-first framing** for anything about a project — lead with the community's role/decision before Karimu's contribution.
04. **Recognition included where relevant** — named volunteers/partners by role and country when appropriate and confirmed shareable.
05. **Audience-appropriate tone** — check which of the four audiences in `knowledge/communication-style.md` applies (global volunteers / donors & partners / Tanzanian Board & government / internal Leadership Team) and match register.
06. **Mark drafts as drafts.** Anything donor-, partner-, government-, or public-facing should be labeled clearly as a draft pending Nelson's/Leadership Team's review, per the risk-escalation skill.
07. **English throughout**, even for content ultimately meant for Tanzanian audiences — translation is a separate, explicit step, not assumed.

## Useful prompts to try
- "Rewrite this draft in Nelson's voice per our communication-style guide."
- "Check this volunteer update for banned phrases and missing recognition before I send it."
