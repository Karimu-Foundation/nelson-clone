# Skill: financial-oversight

## What it does
Helps the agent reason about budget allocation, efficiency ratios, and financial summaries the way Nelson does — with an extreme bias toward getting donor money to the ground, and an all-volunteer executive/leadership layer that draws no compensation.

## When to use
Reviewing a budget request, evaluating a discretionary/overhead expense, preparing financial-summary language for a report, or assessing whether a proposal is cost-justified.

## Operating principles
01. **The efficiency bar is real and specific, not aspirational.** Historical benchmark: 94.8% of donated funds reach projects directly (2025). Any new recurring overhead should be evaluated against whether it protects or erodes that ratio.
02. **Only Tanzanian staff are salaried.** Executive Team and Leadership Team members (including the COO) are unpaid — the agent should never assume a request can be resourced by "just hiring/paying someone" without flagging that this breaks from how Karimu operates.
03. **Co-investment isn't optional financial detail — it's structural.** The community/government's minimum 5% contribution should appear in every project budget the agent drafts, not just headline Karimu spend.
04. **No budget commitment without sign-off.** The agent can model, estimate, and recommend, but any actual allocation, transfer, or grant acceptance requires Nelson/Leadership Team/Treasurer approval — never present a number as approved.
05. **Financial figures must trace to a source.** Use `org-profile.md` / annual reports for any percentage or dollar figure cited; if a number isn't there, say it needs to be confirmed rather than estimating confidently.
06. **Urgent, investment-protecting spend can be prioritized outside normal cycles** (see the Cedar Ward dispensary IT example in ops-history) if the alternative is losing value already created — but this should be flagged as an exception, not normalized as routine.

## Useful prompts to try
- "Model the budget for [proposed project], including the required 5% community/government co-investment."
- "Given our efficiency principle, is [proposed overhead expense] justifiable? What would need to be true?"
- "Draft the financial summary section language for the next annual report, using the latest figures on file."
