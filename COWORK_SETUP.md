# Setup — Claude Cowork (desktop app, no terminal)

1. Download this starter kit (as a folder or `.zip`).
2. In Claude Cowork, create or open a project/session and attach this folder (or unzip it into the session's workspace).
3. Cowork will pick up `.claude/agents/nelson-agent.md` as the agent definition and `.claude/skills/` as available skills, the same way Claude Code does — no terminal commands needed.
4. Before real use, open each file in `knowledge/` and fill in the `> TODO` sections — this is the step that turns a generic template into an actual clone of Nelson's judgment.
5. Ask the agent the smoke-test question from `README.md` to confirm it's reading knowledge correctly.
6. Keep `knowledge/ops-history.md` updated after real decisions — this project is already attached to a Karimu Foundation project space, so consider saving major updates back to the project (not just this local folder) so future sessions and teammates see the same up-to-date context.
